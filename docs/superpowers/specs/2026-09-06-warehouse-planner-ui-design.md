# 仓库轻量专业规划器 UI 设计规格

日期：2026-09-06

## 1. 本轮目标

本轮只设计并实现可评审的前端 UI 稿，不扩展后端接口，不改变库存数据模型，也不实现完整 CAD 几何引擎。

视觉目标以用户提供的仓库平面规划参考图为准：用专业制图画布表现仓库结构、功能区、通道和箱垛，同时延续 BeBeFish ERP 已有导航、字体、颜色和控件风格。

## 2. 页面框架

- 页面采用画布优先的桌面布局，目标视口为 `1440 × 1024`。
- 顶部标题区显示仓库名称与“平面规划”状态。
- 顶部右侧依次展示撤销、重做、测量、网格吸附和“完成规划”。
- 左侧悬浮工具栏包含结构、区域、货物和测量四组工具；货物为默认选中态。
- 中央为带顶部/左侧米制标尺的工程网格画布。
- 右下角显示小地图，底部状态栏显示当前坐标、比例和缩放值。
- 选中对象时，在对象旁显示青色控制点、尺寸标注和悬浮属性卡。

## 3. 画布视觉内容

UI 稿提供一套可直接评审的真实仓库示例：

- 不规则仓库外墙，右侧包含斜边，墙体使用深灰描边与浅灰内填。
- 顶部三个装卸门，显示名称和宽度。
- 收货区、暂存区和发货区使用低饱和绿/蓝色分区。
- 中部与纵向通道显示方向箭头和通道宽度。
- 底部包含设备间和办公区。
- 右侧沿斜墙展示红色消防留空区。
- 货物使用米黄色箱垛/托盘组合，按行列形成清晰的地面堆放阵列，不使用货架造型。
- 示例数据允许同一区域出现多个 SKU，表达 A+B 混放能力。

## 4. 演示交互

本轮交互用于 UI 体验与设计评审：

- 点击左侧工具切换选中态。
- 测量和网格吸附支持开关状态。
- 撤销、重做和完成规划提供明确的点击反馈。
- 点击不同箱垛可切换选中对象及悬浮属性卡。
- 选中卡显示名称、X/Y 坐标、长、宽、旋转角度、库存个数及只读箱数换算。
- 小地图、标尺、缩放状态和尺寸线先作为视觉演示，不承担完整导航或几何计算。
- 现有仓库画布业务能力不作为本轮验收重点；不为视觉稿新增后端保存行为。

## 5. 库存表达规则

- 库存权威展示单位为“个”。
- 箱数根据 SKU 的每箱数量自动换算并标记为只读。
- 同一区域可以出现多个 SKU；每个 SKU 块独立显示编码和数量。
- 箱垛的视觉尺寸表示规划占地，不直接由库存个数推导。
- UI 文案使用“箱垛”“货物”“区域”“通道”，不使用货架、层、格口等货架仓术语。

## 6. 视觉规范

- 整体背景为白色与浅灰蓝工程画布，避免大面积装饰性渐变。
- 仓库墙体采用深灰；结构辅助线使用中性灰。
- 功能区采用低饱和状态色与虚线边界。
- 箱垛采用米黄色纸箱色，并以细线表达单箱分格。
- 选中态使用青色描边、控制点和尺寸线。
- 主操作按钮沿用 BeBeFish ERP 品牌蓝。
- 工具图标使用项目现有图标库，不使用 emoji、手绘 SVG 或占位符。
- 圆角、阴影和间距保持克制，优先突出制图画布的精确感。

## 7. 响应式与可用性

- 以桌面 ERP 为主，保证 `1280px` 至 `1600px` 宽度下核心画布不被裁切。
- 窄视口允许画布水平滚动，顶部操作和左侧工具栏保持可见。
- 所有交互控件保留清晰的悬停、聚焦、选中和禁用状态。
- 文字、尺寸和图标在默认缩放下可读；工具按钮提供中文标签或提示。

## 8. 本轮不包含

- 自由绘制墙体和多边形的生产级算法。
- 拖拽吸附、旋转、节点编辑和真实米制几何计算。
- 消防区、通道占用、越界和重叠校验。
- 库存写入、拆分移库、保存草稿、发布版本和后端接口。
- 3D、多楼层、自动布局和多人协作。

这些能力将在 UI 方向确认后另行设计和排期。

## 9. UI 验收标准

- 页面第一眼与参考图保持同类的专业仓库制图语言，而不是普通卡片式后台页面。
- 顶部工具栏、左侧工具栏、双向标尺、网格、外墙、功能区、通道、箱垛、属性卡、小地图和状态栏全部可见。
- 箱垛明确表现为地面箱子堆砌，不呈现货架结构。
- 示例中可看到多 SKU 共存，以及“个”为主、“箱”为换算的库存表达。
- 核心演示控件可点击并产生符合预期的视觉反馈。
- `1440 × 1024` 页面无遮挡、溢出、文字裁切或失效图标。
- 最终截图需与参考图按相同视口组成对比图进行视觉复核，并至少完成一轮差异修正。
