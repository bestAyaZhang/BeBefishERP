# 仓库手动墙体规划设计

日期：2026-09-06

## 目标与已确认方向

在现有轻量专业规划器中手动规划不规则仓库，统一使用“结构”工具完成外围墙、内部隔墙、装卸门和普通门的绘制与编辑。用户不需要逐段输入精确米数。

用户已通过可视化页面确认两组交互：

1. 节点式外围墙、折线式隔墙、门吸附墙体。
2. 编辑节点、门跟随墙体、货堆越界红框、修复后才能完成规划。

本规格补充实现所需的状态、几何、撤销与验收规则。它覆盖原 UI 规格中墙体只作静态展示的限制；历史上关于货堆尺寸和编辑时库存卡片的描述，以用户后续要求及本规格为准。

## 操作界面

沿用现有顶部操作栏、左侧工具栏、双向标尺和工程网格。选择“结构”后，在画布边缘展示紧凑工具条：选择、外围墙、内部隔墙、装卸门、普通门。

选择墙体后才显示节点及插入节点、删除节点操作。选中门时显示门类型与删除操作。画布内的提示只解释当前动作，不展示 SKU、库存、货堆长宽或坐标属性面板。

结构编辑只在规划模式可用。完成规划后隐藏编辑工具与控制点，点击货堆可在详情面板查看商品、SKU、“个”及按各 SKU 包装规格换算的“件 + 个”。返回规划后隐藏商品详情。

## 绘制与编辑

### 外围墙

- 第一版每个仓库使用一个闭合外轮廓，支持凸形、凹形和斜边。
- 连续点击添加拐点，移动鼠标预览下一段，点击起点闭合；至少三个不共线节点。
- 未闭合的点列是临时草稿；Esc 或取消绘制丢弃本次草稿。重绘期间原边界保留，合法闭合后才整体替换。
- 选中墙体后拖动节点改变轮廓；插入节点时点击对应墙段，删除节点后连接前后两点，至少保留三个节点。
- 不允许自交、零长度边或退化轮廓。无效拖动红色预览，松手恢复该节点的起始位置；无效闭合保留草稿并提示原因。
- 支持现有网格吸附开关及水平、垂直对齐提示，不增加逐段尺寸输入。

### 内部隔墙

- 连续点击创建开放折线，双击或 Enter 结束；至少两个不同节点。Esc 取消本次尚未完成的折线。
- 端点可吸附外围墙或已有隔墙；吸附连接记录墙段及相对位置，使宿主墙变化后接点继续贴合。
- 第一版连接关系只由新隔墙指向已有墙，避免循环依赖。共享端点、T 形连接可用，不允许重叠墙段及未分段的交叉。
- 隔墙可选中后拖动、插入、删除节点，也可整体删除；整体删除和附属门变更作为一次可撤销操作。
- 隔墙必须位于外围墙内，连接外墙的端点允许落在边界上。

### 门

- 选择装卸门或普通门后，指针接近合法墙段显示吸附预览；离墙较远时不能放置。
- 默认装卸门宽 4m、普通门宽 1m；第一版不增加精确宽度编辑器。尺寸仅用于门的几何占位，不进入货堆信息展示。
- 装卸门放在外围墙，普通门可放在外围墙或隔墙。门渲染为真实墙体开口，方向由墙段方向计算。
- 门以宿主墙段 ID 和沿墙相对位置保存，拖动时仅沿该墙段移动；不得越过端点或与同墙段的门重叠。
- 移动墙体节点时，门跟随墙段转动和移动；墙段不足以容纳门时标记问题，阻止完成规划，不悄悄缩小或删除门。
- 拆分、合并墙段时，按原门中心投影重新关联到替代墙段；不能合法放置时保留为待处理门，用户可重新吸附或删除。
- 重绘外围墙后，原外墙上的门保留为待处理门，由用户重新放置；撤销重绘恢复完整原结构。删除隔墙时一并删除其附属门并给出可撤销提示。

## 越界、碰撞与完成规划

结构变化不自动改变货堆位置或商品数量。墙体缩进导致货堆越界时，保留本次有效墙体修改，给受影响货堆加红框并显示“超出仓库边界”。隔墙穿过货堆时同时标记墙段与货堆。

货堆拖动沿用已确认交互：移动对象处于最上层、隐藏 SKU 信息、展示对齐线；拖至冲突位置时标红双方，松手恢复本次拖动前的位置。冲突包括其他货堆、实体墙段和外围边界。已经因改墙而越界的货堆仍可拖回有效位置。

几何判断使用完整货堆矩形与墙体形状，不能只判断中心或四个角；凹形边界可能穿过角点均在内部的矩形。允许刚好贴边，禁止侵入实体墙厚。门开口仍属于仓库边界，不能因此让货堆放到仓外。

问题持续存在时，显示紧凑问题入口及数量；问题列表支持“定位”到对应对象，画布不因裁切而隐藏越界对象。完成按钮禁用并展示原因，问题全部解决后自动恢复。完成处理函数本身再次校验，避免仅依赖按钮状态。

校验项包含：外墙闭合且形状有效、隔墙在仓内且连接有效、门有效吸附且不重叠、货堆在仓内且不侵入墙体、货堆互不重叠。正在绘制或拖动时不能完成规划。

## 状态与模块设计

当前 `WarehouseBlueprintScene.vue` 使用 CSS 固定轮廓，同时以 `warehouseRightBoundary` 与 `constrainedPosition` 单独限制货堆；`WarehouseCanvasView.vue` 维护独立的规划器货堆历史。新结构必须接入这套实际显示的规划器状态，不能误接到旧区域/SKU 画布的保存流程。

新增职责边界：

| 模块 | 职责 |
| --- | --- |
| 结构类型与默认数据 | 稳定 ID 的节点、墙段、外轮廓、隔墙、门及吸附连接；以当前示例初始化 |
| 几何函数 | 点线投影、闭合与自交判断、凹多边形包含、实体墙碰撞、门占位与连接更新 |
| 结构编辑状态 | 当前工具、选中项、临时绘制/拖动、提交命令与取消 |
| 结构图层 | 动态墙体、门开口、节点、草稿、吸附线、错误标记 |
| 页面集成 | 结构与货堆的统一历史、校验结果、完成/返回规划 |

坐标沿用当前绘图区的归一化 0—100 范围，通过一个共享变换映射到屏幕和现有 60m × 40m 标尺。吸附距离和控制点命中范围按屏幕像素判断，墙体几何在逻辑坐标中计算。现有演示货堆米制标签不是精确测绘依据，不用它反推结构坐标。

外墙填充、实体描边、门开口、货堆约束和小地图读取同一份结构数据。绘图区保留边界外的纠错空间。现有设备间、办公区墙线应纳入隔墙数据，避免出现显示为墙却无法编辑或校验的情况；区域、通道和消防色块继续作为示意标注，不参与新增结构模型的自动布置。

库存明细保持现有来源。墙体模块不生成、拆分或合并 SKU，也不修改货堆总个数。

## 撤销、性能与保存

- 完成一条墙、一次节点拖动、一次门移动、一次货堆移动各产生一个历史步骤；历史同时保存结构、连接、门和货堆。
- 指针移动只更新临时预览，使用 requestAnimationFrame 合并更新，松手后提交一次；不在每个移动事件里复制整张仓库布局。
- Esc、pointercancel 或中断拖动恢复动作前状态；无效回弹、选择对象、切换工具不产生布局历史步骤。
- 撤销与重做同步恢复门的宿主关系，并重新计算问题。卸载时清理指针捕获、动画帧与反馈定时器。
- 第一版延续当前前端演示会话的保存边界：“完成规划”校验并切换查看模式，返回规划保留当前编辑结果；刷新页面仍恢复演示数据。界面不得将它描述为后端持久保存。
- 后端保存、跨设备同步、仓库正式发布和浏览器持久草稿不属于本次墙体交互开发。

## 验收

1. 能绘制并编辑有斜边和凹角的外围墙，闭合、插点、删点、取消动作符合上述规则。
2. 能创建 L 形隔墙、建立吸附连接、编辑及删除，撤销恢复其门和连接。
3. 装卸门和普通门能吸附合法墙段并沿墙移动；墙段转动后门仍贴合，不足长度的墙段产生可定位问题。
4. 收缩墙体让货堆越界时红框可见，不能完成；把货堆移回仓内后问题消失，恢复完成操作。
5. 凹边穿过货堆、隔墙穿过货堆、相邻货堆重叠均被正确识别；仅贴边不误报。
6. 一次完整拖动只撤销一次；拖动取消不改变最终布局。移动货堆置顶、对齐线和冲突回弹不回归。
7. 完成模式不允许编辑墙体，查看详情显示商品；返回规划不出现 SKU 属性面板。
8. 外轮廓与小地图一致；1280—1600px 桌面宽度下工具、问题入口、节点与标尺无非预期溢出。
9. 验证几何及历史的关键测试、画布和页面交互测试，运行前端类型检查与构建，并在浏览器实际检查绘制、编辑、碰撞、撤销及完成流程。
