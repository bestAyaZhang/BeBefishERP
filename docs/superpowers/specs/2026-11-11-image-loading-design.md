# 商品图片加载优化

用户已确认采用七牛 CDN、按显示尺寸加载预览图和非首屏按需加载的方案，并授权实施、测试和上线。

当前图片均通过 ERP 下载完整七牛原图后返回；列表约 52px 的图片同样下载原图。抽样 1,282,306 字节的 PNG 单张约 3 秒；116 张商品封面中 67 张超过 1MB。图片原件及商品、SKU、文件 ID 必须保留。

## 方案

采用稳定的已有图片地址，增加受控 `variant=thumb`（160px）和 `variant=preview`（800px）两种预览。已验证的 HTTPS 七牛正式 CDN 域名配置完成后，预览请求重定向到带图片处理参数的签名 CDN 地址；图片字节直接由 CDN 返回。保留原图接口供放大、下载和素材包使用。

如果 CDN 尚未就绪，服务端生成等比、不裁剪的预览并缓存到本机磁盘，以便缩略图改造能够独立上线。透明图片保留透明；其他图片使用 JPEG。限制并发解码和预览尺寸，避免大图拖垮服务。预览缓存使用独立文件名、原子写入和容量上限；相同原图 key 不覆盖，因此可使用长期浏览器缓存。

前端集中处理预览地址，仅处理 ERP 管理的图片，保留其他 URL、查询参数和原图下载。列表、SKU 小图、相册使用 thumb，详情主图使用 preview 并优先加载，其余图片 lazy。点击放大及下载仍访问原图。

## 取舍

- 只增加服务器带宽不能消除不必要的原图传输，不采用。
- 直接替换或压缩原件会影响导出资料，不采用。
- CDN 加尺寸预览为主，磁盘缓存预览为域名未就绪时的兼容路径。CDN 需真实验证 DNS、HTTPS、私有资源签名及图片处理，不把测试域名作为正式地址启用。

## 验收

原图和所有商品资料不变；160px 列表图片不下载大原图；800px 主图不被懒加载；放大和下载仍读取原件；错误尺寸请求在读取七牛前拒绝；测试覆盖缓存复用、透明 PNG、长图、无效输入、CDN 签名和参数顺序。上线后对比同一图片大小和耗时，检查商品列表、详情和放大预览。
