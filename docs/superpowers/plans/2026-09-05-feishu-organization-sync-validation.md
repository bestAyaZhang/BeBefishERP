## 限制

当前没有真实飞书租户应用凭据，因此未执行真实企业通讯录的端到端导入。飞书分页和状态映射使用真实 HTTP 客户端连接受控接口响应进行测试，数据合并使用真实 MySQL；本地浏览器验证了未配置时的实际失败任务。

调度按已确认设计支持单实例；多实例部署需要数据库锁或分布式锁。导航目录为本地静态路由配置，并非业务 Mock 数据。
