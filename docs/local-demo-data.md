## 体验路径

1. 打开「商品资料」，搜索「演示」，查看商品规格、包装参数、成本和供应商报价。
2. 打开「库存余额」，选择杭州演示仓或义乌演示仓，查看库存。
3. 打开「客户管理」，进入演示客户的「货品 / 账单」，查看专属单价及应收、已收、欠款。
4. 点击「给客户开单」，选择演示仓库及货品。专属价格自动带入；未设置专属价的货品使用默认价。
5. 查看已确认销售单，使用「打印」预览送货单，或从客户账单打印对账单。

所有商家、联系人和联系方式均为虚构，演示单据不代表真实交易。未接入物流，也不会自动打印或实际发货。

## 重复生成

在项目根目录使用 PowerShell 7 执行 `./scripts/seed-local-demo.ps1`。脚本只支持 `.env.local` 指定的本机 `bebefish_erp`，执行前自动备份数据库，通过 API 写入。已有演示档案按固定编号复用，已保存的客户价格保留。库存和单据恢复记录位于 `.tools/demo-seed-state.json`，不要删除后再次生成，以免丢失库存去重依据。

本次生成前的备份：`backups/before-demo-seed-20261014-151537.sql`。备份和运行记录均不提交到版本库。
