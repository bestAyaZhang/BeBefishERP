# 阶段 0：项目准备与原型确认

## 1. 阶段目标

阶段 0 的目标是在正式编码前确认 ERP 第一版的页面范围、菜单结构、字段口径、单据编号、环境配置和验收口径。该阶段完成后，前端可以按页面拆任务，后端可以按字段和流程编写数据库迁移脚本与接口，项目负责人可以按阶段验收开发进度。

当前状态同步：

- 阶段 0 已完成文档、页面范围和阶段 1 开发入口确认。
- 项目已进入阶段 1，`main` 已包含登录基础接口和登录页 UI 调整。
- 本文档继续作为第一版页面范围和原型基线，登录页部分已同步当前实现要求。

## 5. 核心页面原型说明

本阶段先使用低保真原型，不追求视觉细节。所有后台页面优先采用列表、筛选、表单、详情抽屉和二次确认弹窗。

### 5.1 登录页

- 页面采用黑白主配色，左侧为黑色交互动效面板，右侧为白色登录表单。
- 左侧动效面板不展示“等待输入”、库存、线下开单、财务看板、平台数据等辅助文案，避免遮挡。
- 右侧显示系统名称和登录表单。
- 手机号、密码、验证码字段标签使用大写英文：`MOBILE`、`PASSWORD`、`SMS CODE`。
- 登录方式切换放在密码或验证码输入区下方两端，仅显示“密码”和“验证码”文字，不使用小图标。
- 密码登录字段：手机号、密码。
- 验证码登录字段：手机号、验证码、发送验证码按钮。
- 飞书登录第一版只展示禁用态预留入口，不调用飞书 OAuth。
- 登录成功后进入首页；当前阶段登录成功先展示用户和权限结果，后台首页后续补齐。

### 5.2 经营总览

- 顶部日期筛选。
- 指标卡片：销售额、订单数、毛利、应收、应付、库存预警。
- 平台销售汇总表。
- 库存预警列表。

### 5.3 产品与 SKU

- 产品列表支持按货号、产品名称、分类、状态筛选。
- SKU 列表支持按 SKU 编码、条码、货号、规格、状态筛选。
- SKU 表单分区：基础信息、价格成本、包装资料、图片信息。
- 包装资料包含包装长宽高、体积、净重、毛重、克重、包装方式、装箱数、包装图片。

### 5.4 采购单

- 主信息：供应商、仓库、采购日期、备注。
- 明细：物料或 SKU、数量、单价、金额。
- 草稿可编辑，确认后生成库存流水和应付。
- 已确认单据只能查看、打印或作废。

### 5.5 组装入库单

- 主信息：成品 SKU、组装数量、仓库、备注。
- 系统读取 BOM 展示所需物料、库存数量、是否充足。
- 确认后扣物料库存、加成品库存。

### 5.6 销售开单

- 主信息：客户、仓库、销售日期、收款方式、收款金额。
- 明细：SKU、数量、单价、折扣、金额。
- 确认后扣成品库存，生成应收和收款记录。
- 支持打印或导出销售单。

## 6. 字段确认表

### 6.1 产品/SPU

| 字段 | 是否必填 | 说明 |
| --- | --- | --- |
| 产品编码 `product_code` | 是 | 系统内部编码，唯一 |
| 货号 `item_no` | 是 | 业务货号，唯一 |
| 产品名称 `product_name` | 是 | 产品对内显示名称 |
| 分类 `category_name` | 否 | 第一版可先文本维护 |
| 品牌 `brand_name` | 否 | 第一版可先文本维护 |
| 状态 `status` | 是 | enabled、disabled |

### 6.2 SKU

| 字段 | 是否必填 | 说明 |
| --- | --- | --- |
| SKU 编码 `sku_code` | 是 | 具体规格编码，唯一 |
| 所属产品 `spu_id` | 是 | 关联产品/SPU |
| 条码 `barcode` | 否 | 预留扫码 |
| SKU 名称 `sku_name` | 是 | 对内显示名称 |
| 规格 `spec_text` | 否 | 例如颜色、尺寸、容量 |
| 默认售价 `sale_price` | 是 | 线下开单默认带出 |
| 标准成本 `standard_cost` | 否 | 可由 BOM 计算 |
| 包装长 `package_length_cm` | 否 | 单位 cm |
| 包装宽 `package_width_cm` | 否 | 单位 cm |
| 包装高 `package_height_cm` | 否 | 单位 cm |
| 包装体积 `package_volume_cm3` | 否 | 单位 cm³ |
| 净重 `net_weight_kg` | 否 | 单位 kg |
| 毛重 `gross_weight_kg` | 否 | 单位 kg |
| 克重 `gram_weight_g` | 否 | 单位 g |
| 包装方式 `package_type` | 否 | 彩盒、白盒、OPP 袋等 |
| 包装图片 `package_image_url` | 否 | 文件地址或对象存储 URL |
| 装箱数 `carton_quantity` | 否 | 正整数 |

### 6.3 物料

| 字段 | 是否必填 | 说明 |
| --- | --- | --- |
| 物料编码 `material_code` | 是 | 唯一 |
| 条码 `barcode` | 否 | 预留扫码 |
| 物料名称 `material_name` | 是 | 对内显示名称 |
| 单位 `unit` | 是 | 个、套、米、kg 等 |
| 标准成本 `standard_cost` | 是 | BOM 成本计算来源 |
| 默认供应商 `main_supplier_id` | 否 | 可后续补充 |

## 7. 单据编号规则

| 单据 | 编号前缀 | 示例 | 规则 |
| --- | --- | --- | --- |
| 采购单 | `PO` | `PO202607050001` | 前缀 + 日期 + 4 位流水 |
| 组装单 | `AS` | `AS202607050001` | 前缀 + 日期 + 4 位流水 |
| 销售单 | `SO` | `SO202607050001` | 前缀 + 日期 + 4 位流水 |
| 库存调整单 | `SA` | `SA202607050001` | 前缀 + 日期 + 4 位流水 |
| 费用单 | `EX` | `EX202607050001` | 前缀 + 日期 + 4 位流水 |

编号由后端统一生成，前端不生成业务单号。
