# 电商内部 ERP 需求文档

## 1. 项目定位

本系统是公司内部使用的电商 ERP，用于统一管理产品、SKU、物料、库存、采购、线下开单、财务经营流水、员工资料、轻量考勤，以及各电商平台数据汇总看板。

第一阶段目标不是直接开发全部功能，而是形成可报价、可排期、可进入开发拆任务的需求边界。系统按 20 人以内团队、单仓库、多电商平台数据导入、云服务器 Web 访问设计。

## 2. 建设目标

- 让产品、SKU、物料、BOM、库存和成本有统一数据源。
- 让采购入库、组装入库、线下销售开单形成完整库存流水。
- 让销售单、采购单和收付款形成基础经营流水，不做完整会计总账。
- 通过 Excel/CSV 导入各平台数据，形成经营总览看板。
- 支持员工、角色、权限、轻量排班考勤，满足内部管理需要。
- 为后续平台 API 对接、多仓库、扫码、审批、完整财务等能力预留扩展空间。

## 3. 用户角色

| 角色 | 核心职责 | 主要权限 |
| --- | --- | --- |
| 老板/管理员 | 查看全局经营数据，管理基础资料和权限 | 全部菜单、成本、利润、财务、系统设置 |
| 仓库人员 | 处理入库、出库、库存查询、盘点 | 库存、采购入库、组装入库、销售出库相关操作 |
| 销售/开单人员 | 维护客户、创建线下销售单、收款记录 | 客户、销售开单、销售查询、基础库存查询 |
| 财务人员 | 管理收付款、应收应付、费用、经营流水 | 财务、采购应付、销售应收、费用、报表 |
| 采购人员 | 管理供应商、采购单、采购入库 | 供应商、采购、物料成本 |
| 人事/行政 | 管理员工档案、班次、考勤 | 员工、排班、考勤 |

第一版采用角色权限模型，控制菜单和按钮级操作。不做字段级权限，但成本、利润、财务菜单默认只开放给老板/管理员和财务人员。

## 4. MVP 范围

### 4.1 登录与认证

- 第一版员工使用手机号作为主要登录标识。
- 登录页支持两种方式：手机号 + 密码、手机号 + 短信验证码。
- 登录成功后，系统按用户绑定角色加载菜单和操作权限。
- 禁用员工或禁用用户不能登录。
- 短信验证码 5 分钟有效，同一手机号 60 秒内不可重复发送。
- 验证码校验成功后立即失效。
- 未来预留飞书登录能力，第一版不做飞书 OAuth 登录，只保留用户绑定字段和扩展接口边界。
- 登录页当前确认采用黑白主配色，左侧交互动效面板不展示辅助遮挡文案，右侧表单字段标签使用 `MOBILE`、`PASSWORD`、`SMS CODE`。
- 密码/验证码切换放在凭证输入区下方两端，仅用文字展示；飞书登录可展示禁用态预留入口。

### 4.2 基础资料

- 产品/SPU：维护产品名称、货号、分类、品牌、状态、备注。
- SKU：维护规格、编码、条码、售价、标准成本、关联产品、包装尺寸、体积、净重、毛重、克重、包装方式、包装图片、装箱数。
- 物料：维护物料编码、名称、单位、条码、标准成本、供应商。
- BOM：维护成品 SKU 与物料用量，用于组装入库和标准成本计算。
- 客户：维护客户名称、联系人、手机号、地址、欠款余额。
- 供应商：维护供应商名称、联系人、手机号、地址、结算信息。
- 员工：维护员工资料、岗位、角色、入职状态。

### 4.3 库存管理

- 第一版按单仓库使用，但数据库保留仓库字段。
- SKU 和物料都纳入库存管理。
- 所有库存变化必须生成库存流水。
- 库存流水来源包括采购入库、组装入库、销售出库、作废冲回、手工调整。
- 支持库存查询、库存预警、库存流水追溯。
- 条码字段先预留，第一版不强制扫码操作。

### 4.4 采购与供应商

- 支持创建采购单，采购对象可以是物料或成品 SKU。
- 采购单确认后形成采购入库，增加库存。
- 采购单确认后形成应付记录。
- 支持记录付款，更新应付状态。
- 不做采购申请、审批、合同、质检等复杂流程。

### 4.5 BOM 与组装入库

- BOM 用于定义一个成品 SKU 需要消耗哪些物料及数量。
- 组装入库单选择成品 SKU 和组装数量。
- 系统按 BOM 自动计算应扣物料数量。
- 组装单确认后扣减物料库存，增加成品 SKU 库存。
- 组装成本按物料标准成本和 BOM 用量计算，并记录到组装单。
- 第一版不做工序、工时、损耗分摊、生产计划。

### 4.6 线下销售开单

- 支持选择客户、销售 SKU、数量、单价、折扣、备注。
- SKU 默认带出售价，但允许手工改价。
- 销售单确认后自动扣减 SKU 库存。
- 支持记录收款金额，未收部分形成应收。
- 支持打印或导出销售单。
- 第一版不做完整退换货售后流程，但预留作废和冲回规则。

### 4.7 财务经营流水

- 财务第一版定位为经营流水管理，不做会计总账、凭证、报税。
- 支持销售应收、采购应付、收款、付款、费用登记。
- 费用可按类型归类，例如快递、平台费、人工、耗材、办公、其他。
- 看板按销售额、成本、费用、毛利、应收、应付等维度统计。

### 4.8 平台数据导入与看板

- 第一版通过 Excel/CSV 导入平台订单、销售、费用等数据。
- 优先覆盖 1688、淘宝/天猫、拼多多、抖音、京东的数据映射。
- 导入记录按批次保存，支持查看导入结果和错误行。
- 看板提供经营总览：销售额、订单数、毛利、库存预警、应收应付、平台销售汇总。
- 第一版不直接对接平台 API，但数据模型保留平台、店铺、外部订单号字段。

### 4.9 员工、排班与考勤

- 员工管理包括姓名、手机号、岗位、角色、入职日期、状态。
- 排班管理包括班次名称、上班时间、下班时间。
- 考勤支持手工录入或表格导入。
- 统计员工出勤天数、迟到早退次数、请假备注。
- 第一版考勤不接入打卡设备、钉钉、飞书，也不做完整薪资核算。

## 5. 单据状态规则

销售单、采购单、组装单、库存调整单等业务单据统一采用轻量状态流。

| 状态 | 含义 | 允许操作 |
| --- | --- | --- |
| 草稿 | 单据尚未生效 | 可编辑、可删除、可确认 |
| 已确认 | 单据已影响库存或财务 | 不允许直接编辑，可查看、打印、作废 |
| 已作废 | 单据已冲回或失效 | 只允许查看 |

确认后的单据不允许随意修改历史数据。需要纠错时，通过作废、冲回或重新开单处理，保证库存流水和财务流水可追溯。

## 6. 核心业务流程

### 6.1 产品与成本流程

1. 创建产品/SPU，录入产品名称和货号。
2. 创建 SKU，录入规格、售价、条码、包装尺寸、体积、净重、毛重、克重、包装方式、包装图片、装箱数。
3. 创建物料，录入标准成本。
4. 配置 SKU 的 BOM。
5. 系统按 BOM 计算 SKU 标准成本。

### 6.2 采购入库流程

1. 创建供应商。
2. 创建采购单，选择物料或 SKU。
3. 填写采购数量、采购单价、预计到货日期。
4. 确认采购单。
5. 系统增加库存，生成库存流水和应付记录。
6. 财务登记付款，更新应付状态。

### 6.3 组装入库流程

1. 选择成品 SKU 和组装数量。
2. 系统读取 BOM，计算所需物料。
3. 检查物料库存是否充足。
4. 确认组装单。
5. 系统扣减物料库存，增加成品库存，记录组装成本。

### 6.4 线下开单流程

1. 选择客户。
2. 添加销售 SKU、数量、单价。
3. 填写收款方式和收款金额。
4. 确认销售单。
5. 系统扣减成品库存，生成库存流水。
6. 未收部分生成应收，已收部分生成收款记录。
7. 销售单进入经营看板。

### 6.5 平台导入流程

1. 选择平台和店铺。
2. 上传 Excel/CSV 文件。
3. 系统按平台模板解析字段。
4. 校验订单号、金额、日期、SKU 映射。
5. 保存导入批次、成功行和失败行。
6. 成功数据进入平台销售汇总看板。

## 7. 非 MVP 蓝图

- 多仓库、仓库调拨、库位管理。
- 扫码入库、扫码出库、扫码盘点。
- 退货、换货、退款、售后工单。
- 平台 API 授权、自动拉单、定时同步。
- 完整审批流程，例如采购审批、付款审批、作废审批。
- 完整会计模块，例如科目、凭证、总账、资产负债表。
- 工资核算、请假加班、打卡设备或第三方考勤系统同步。
- 生产计划、工序、损耗、工时和制造费用分摊。

## 8. 非功能需求

- 云服务器部署，员工通过浏览器访问。
- 支持 PC 浏览器优先，移动端只保证基础查看能力。
- 关键单据确认操作必须记录操作人和操作时间。
- 重要业务数据采用逻辑删除，避免误删。
- 数据库每天自动备份，保留至少 30 天。
- 导入文件和导出文件需保存操作记录。
- 常用列表查询需支持分页、筛选、排序。
- 金额统一使用 decimal 类型，避免浮点误差。

## 9. 验收场景

- 产品建档后能维护 SKU、包装资料、物料、BOM，并计算标准成本。
- 采购入库能增加物料或成品库存，并形成应付。
- 组装入库能扣减物料库存、增加成品库存，并记录成本。
- 线下开单能扣库存、记录收款或欠款，并进入经营看板。
- 平台 Excel/CSV 导入后能汇总销售额、订单数、毛利等指标。
- 单据确认后不可直接修改，只能作废或按规则冲回。
- 不同角色只能访问对应菜单和操作。
