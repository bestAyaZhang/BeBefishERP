# 客户管理

## 需求与使用

客户档案维护姓名、联系人、电话、配送地址、平台、运输方式及结算周期。平台复用平台管理，初始提供拼多多、1688、散户，支持在平台管理扩展；已有客户暂不分配平台，避免误分类。

客户详情提供「货品与专属价格」和「客户账单」。每个客户、每个 SKU 保存一个专属单价，允许零价格，精确到分。开单选客户后带入运输和结算约定，添加货品优先使用客户价，未设置时用商品默认售价；允许开单时手工改价。切换客户后按新客户重新带入价格，并提示。确认后的历史单据保留当时的价格和商品快照。

销售开单的客户选择支持输入姓名、客户编号、联系人或电话搜索，结果显示客户名称、编号、联系人和电话，支持鼠标选择及方向键、回车选择，Escape 或离开输入框关闭结果。仅输入文字不视为选中客户；编辑或清空已选客户后必须重新选择，避免误用原客户。由客户详情进入开单时仍自动选中该客户。

账单按客户 ID、开单日期范围查询，分页展示已确认销售单，汇总范围内全部单据的应收、开单时登记的已收及欠款；草稿和作废单据不计入。点击单号看商品明细。第一版不包含开单后的补收款、退款和税务发票。

从客户详情「给客户开单」进入销售开单，确认后可以打开保存的销售单打印送货单。客户账单可打印所选日期范围的全部对账明细。点击打印入口后先显示页面内的 A4 预览，核对内容后点击「打印」调用浏览器系统打印窗口，选择电脑已安装的打印机，支持另存 PDF。若内置浏览器无法调起系统打印窗口，可点击「下载单据」，在 Chrome 或 Edge 中打开 HTML 单据后打印；系统不声称已实际出纸。

保存草稿暂不扣库存；开单页面或草稿详情点击「确认下单并扣库存」后，按每项货品（SKU）的数量扣减所选发货仓库库存，同时记录库存流水。任一货品库存不足时整单确认失败，保留草稿，库存及流水不变。同一张销售单重复或并发确认仅扣减一次；已确认单据作废时退回原仓库，重复作废不会多退。详情中的库存提示随单据状态更新，确认后的单据可以打印送货单。

## 数据库

V28 迁移在 customer 增加可空 platform_id，外键关联 sales_platform；建立 customer_sku_price，唯一键 (customer_id, sku_id)，金额 decimal(18,2)、非负约束、更新人及更新时间。历史单据继续使用 sales_order 和 sales_order_item，不重复存账单。

## API 与权限

- 客户读写接口增加 platformId，可空；新增/更换平台必须存在且启用，保留原停用平台允许编辑其他字段。
- GET /api/customers/platform-options：平台选项（含停用平台供历史展示），customer:view。
- GET /api/customers/{id}/prices：专属货品及价格，customer:view 或 sales:create。
- PUT /api/customers/{id}/prices/{skuId}：{unitPrice}，customer:edit；校验客户、商品及 SKU 启用，金额非负且最多两位小数。
- DELETE /api/customers/{id}/prices/{skuId}：取消专属价格，customer:edit。
- GET /api/customers/{id}/bills?page=1&size=20&dateFrom=YYYY-MM-DD&dateTo=YYYY-MM-DD：返回分页单据和整个筛选范围的 summary，customer:view 且 sales:view。打印逐页读取全部记录。

写操作使用事务，真实接口失败不回退到模拟写入。前端权限控制与后端权限校验同时生效。
