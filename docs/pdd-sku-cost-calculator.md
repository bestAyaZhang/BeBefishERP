# 拼多多 SKU 成本计算

本地功能入口：软件工具 → 拼多多成本计算，路由 `/tools/pdd-cost`（兼容原 `/products/pdd-cost`）。用于定价测算及保存方案，不调用拼多多接口，不调整商品资料、库存或线上售价。

## 实际参考与操作

2026-10-15 查看本地狗宝助手 1.118「商品管理 → 利润率计算」：按商品选择表格，行内编辑规格、成本、快递、售价、利润率、售后率、开车投产比、成交出价，展示总成本、利润、实际保本投产比、预计到手利润率及金额；提供新增商品、增删行和提交保存。ERP 参考这种逐规格编辑和保存方式，没有复制或修改参考软件中的经营数据。

ERP 支持新建方案，搜索已有 SKU 带入标准成本与默认售价，或直接手工添加规格；成本参数可逐行编辑，并增加包装费、其他成本、平台费率；推广选择不计推广、按投产比或按成交出价。可以填目标毛利率并逐行反推售价。复制行用于比较不同价格或投产场景，复制方案用于保留原方案。保存后可重新打开、编辑、按名称搜索、分页、归档和恢复。

所有参数由用户填写；初始 0 表示尚未计入相关费用，不代表官方费率或真实店铺数据。新行的货品成本、售价必须明确填写，售价必须大于零；推广方式为投产比时必须填写正投产比。规格必须命名，每个方案最多 200 行。未保存的修改在切换方案、离开页面或刷新时提示。

点击菜单自动打开 SKU 利润测算弹框，全部指标适应窗口宽度，小窗口以分组网格展示。规格较多时按窗口高度分页，避免横向和纵向滚动；翻页不会丢失输入，保存包含整个方案。关闭弹框保留当前编辑，可从页面再次打开。

## 计算口径（版本 1）

金额为元/单，售后率与平台费率以百分数输入。

- 总成本 C = 货品成本 + 快递费 + 包装费 + 其他成本。
- 毛利润 G = 售价 P − C；毛利率 = G / P。
- 推广前利润 B = (G − P × 平台费率) × (1 − 售后率)。
- 保本投产比 = P / B；B ≤ 0 时显示“无法保本”，不显示 Infinity 或 NaN。
- 推广费 A：不计推广为 0；按投产比为 P / ROI；按成交出价为填写的单笔成交出价。两种推广口径互斥，避免重复扣费。
- 预计到手利润 = B − A；预计到手利润率 = (B − A) / P。亏损保留负值。
- 目标毛利率 m 反推售价 = C / (1 − m)，售价向上取整到分。

售后订单不计商品毛利，但推广费仍计入；平台费按未退款成交额计提。未单独模拟退货运费、货损和税费，请按实际情况填入其他成本。本模块是估算模型，实际利润仍需结算及售后数据核对。计算不对中间保本投产比或毛利率提前四舍五入；后端 BigDecimal 权威计算，金额最后保留 2 位，比例保留 4 位，页面显示 2 位。因此可能与参考软件的中间取整结果略有差异。

## 保存与接口

V29 新增独立表 `pdd_sku_cost_plan`，保存名称、备注、所有规格输入快照、公式版本、归档状态、乐观锁版本、操作人和时间。关联 SKU 仅保存其 ID 和编码快照；每次保存校验 SKU 存在且启用。后端重新计算结果，不信任浏览器提交的利润数字。并发编辑时旧版本无法覆盖新版本，返回 409；失败保留页面编辑内容。

- GET `/api/product-cost-plans?keyword=&archived=false&page=1&size=20`：分页方案。
- GET `/api/product-cost-plans/sku-options?keyword=`：最多 50 个启用 SKU，关键词支持商品名、货号、SKU 名与编码。
- GET `/api/product-cost-plans/{id}`：已保存输入和重新核算的结果。
- POST `/api/product-cost-plans`：新建，body 为 name、remark、lines。
- PUT `/api/product-cost-plans/{id}`：更新，必须携带 version。
- POST `/api/product-cost-plans/{id}/archive?version=`：归档，可恢复。
- POST `/api/product-cost-plans/{id}/restore?version=`：恢复。

查看及搜索需 `product:view`，新建、编辑、归档及恢复需 `product:edit`。真实模式保存到 MySQL，网络失败不回退本地模拟保存。模拟模式仅在显式开发模拟环境中使用浏览器存储。
